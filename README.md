# Pokémon Battle Simulator

A French Pokémon-inspired battle simulator developed in Python.

This project allows players to create teams of Pokémon, engage in turn-based battles, and experience core Pokémon mechanics through a custom-built battle system. It was developed as a French educational project to practise object-oriented programming, game logic design, and Python development.

\---

## Features

* Turn-based Pokémon battles
* Multiple Pokémon species
* Individual Pokémon statistics
* Move and attack system
* Hit points (HP) management
* Damage calculation
* Team selection and management
* Battle outcome determination
* Console or graphical gameplay (depending on implementation)

\---

## Gameplay

Players choose their Pokémon and battle against opponents using different moves and strategies.

During each turn, Pokémon can:

* Attack opponents
* Use special moves
* Deal damage based on their statistics
* Faint when their HP reaches zero

The match continues until one side has no Pokémon remaining.

## Installation

### Clone the repository

```bash
git clone https://github.com/Z19Z19/Z19PokemonBattleSim.git
cd Z19PokemonBattleSim
```
### Install dependencies

```bash
pip install json requests
```


## Running the Project

```bash
python main.py
```
